This repository contains Python code from my research in reinforcement learning, using the Gymnasium API to simulate the Half-Cheetah environment. I implemented Proximal Policy Optimization (PPO) and leveraged a UCB-based meta-learning strategy to iteratively select the most effective learning rate. Through experimentation, I found that a learning rate of 0.0001 yielded the best results, achieving a normalized episodic return of 1 at 45,000 steps. A slightly higher learning rate of 0.0005 also performed well, while extremely low learning rates, such as 5e-7, resulted in poor performance.
